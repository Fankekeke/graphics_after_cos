# 基于 SpringBoot + Vue 的显卡售后服务系统 (GPU After-Sales Service System)

工单管理 · 维修流程 · 在线缴费 · 预约服务 · 产品序列号 · 评价管理 · 公告通知 · 支付宝支付

本项目是一套面向显卡品牌商、授权维修中心及电脑硬件售后服务的工单管理系统，采用前后端分离架构，覆盖管理员、客户与维修员三类角色。系统围绕"工单管理、维修流程、在线缴费、预约服务、产品序列号管理、评价管理、公告通知"等核心业务设计，支持客户在线提交维修工单、预约服务时间、支付宝在线缴费、查看维修进度，维修员接收任务并执行维修流程，管理员负责工单分配、维修信息管理、产品与员工管理、数据统计与公告发布，实现从工单提交、维修处理、费用缴纳到服务评价的全流程数字化管理，适用于显卡厂商售后中心、电脑硬件维修服务站、数码产品售后服务网点。

## 核心特性

- **多角色权限管理**：区分管理员、客户与维修员三类角色，实现不同权限隔离与功能访问控制。
- **工单全流程管理**：客户在线提交维修工单，管理员分配维修员，维修员执行维修流程并更新状态，客户实时查看进度。
- **产品序列号管理**：通过产品序列号（SN码）绑定显卡产品信息，包括型号、购买日期、保修状态、保修期限，实现产品溯源与保修验证。
- **预约服务**：客户可预约维修时间与服务类型（上门取件/到店送修/邮寄维修），系统自动排期并通知维修员。
- **维修流程管理**：维修员按标准化流程执行检测、报价、维修、测试、完工，每个环节可记录操作内容与更换配件。
- **支付宝在线缴费**：维修报价确认后，客户通过支付宝在线支付维修费用，支付成功后维修员继续执行维修。
- **评价管理**：客户完成维修后可对服务进行评分与评价，评价信息供管理员查看与统计分析。

## 功能模块概览

## 管理员端

管理员负责平台整体运营、工单管理、员工管理、产品管理、维修信息管理与公告发布：

### 用户与员工管理

- **用户管理**：管理注册客户信息，包括姓名、手机号、注册时间、账户状态，支持账号启用/禁用。
- **员工管理**：管理维修员信息，包括姓名、工号、手机号、专业技能、入职时间、工作状态，支持维修员审核与禁用。

### 产品与服务管理

- **产品信息**：管理显卡产品型号信息，包括品牌、型号、系列、规格参数、官方保修期限。
- **产品序列号**：管理产品序列号（SN码）与产品的绑定关系，记录购买日期、购买渠道、保修状态（在保/过保）、保修截止日期，支持序列号查询与保修验证。
- **服务类型**：配置服务类型，如显卡维修、风扇更换、散热膏更换、BIOS升级、外观检测等，支持设置服务收费标准。

### 工单与维修管理

- **工单管理**：查看所有工单列表，包括工单状态（待分配/待维修/维修中/待缴费/已完成/已取消）、客户信息、产品信息、维修员、创建时间，支持按状态、时间、产品筛选与工单分配。
- **预约管理**：查看客户预约的维修服务，包括预约时间、服务类型、取件方式，支持排期确认与通知维修员。
- **维修信息**：查看所有维修记录详情，包括故障描述、检测结果、更换配件、维修费用、维修时长、维修员备注。
- **缴费记录**：查看所有客户的缴费历史记录，包括缴费时间、金额、支付方式、订单号、缴费状态，支持按时间、客户筛选。

### 评价与公告管理

- **评价管理**：查看客户对维修服务的评价内容、评分与标签，支持评价审核与异常评价处理，统计平均评分与服务满意度。
- **公告信息**：发布平台公告，包括售后服务政策变更、维修通知、节假日安排、系统维护通知等，支持置顶与定时发布。

## 客户端

客户面向注册用户，提供工单提交、维修进度查看、在线缴费与评价功能：

### 账户与个人信息

- **个人信息**：查看与维护个人基本信息，包括姓名、手机号、常用地址、联系邮箱。

### 工单与维修

- **我的工单**：查看个人提交的维修工单列表，包括工单状态（待分配/待维修/维修中/待缴费/已完成/已取消）、工单详情、维修进度、维修员信息。
- **维修信息**：查看工单对应的维修详情，包括故障描述、检测结果、更换配件清单、维修费用报价、维修完成时间。

### 缴费与评价

- **缴费记录**：查看个人缴费历史记录，包括缴费时间、金额、支付方式、订单号、缴费状态，支持导出缴费凭证。
- **支付宝在线缴费**：维修报价确认后，通过支付宝在线支付维修费用，支付成功后工单状态更新，维修员继续执行维修。
- **工单评价**：工单完成后可对维修服务进行评分（1-5星）与文字评价，支持上传评价图片。

### 公告查看

- **查看公告**：浏览管理员发布的公告信息，了解售后服务政策、维修通知与系统公告。

---

## 维修员端

维修员面向平台注册维修员，提供任务接收、维修流程执行与公告查看功能：

### 任务管理

- **我的任务**：查看分配给个人的维修工单列表，包括工单状态（待维修/维修中/待缴费/已完成）、客户信息、产品信息、故障描述、预约时间。

### 维修流程

- **任务维修流程**：按标准化流程执行维修操作，包括：
  - **检测**：记录显卡故障检测结果与检测图片
  - **报价**：填写维修费用报价与更换配件清单，提交客户确认缴费
  - **维修**：执行维修操作，记录维修过程与更换配件详情
  - **测试**：维修完成后进行功能测试，记录测试结果
  - **完工**：确认维修完成，通知客户取件/寄回

### 公告查看

- **查看公告**：浏览管理员发布的公告信息，了解工作安排、政策变更与系统通知。
